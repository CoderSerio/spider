## 可选的本机模型（实验性）

在设置的「模型」里打开「本机模型」，再点「加载本机模型」。在线配置会隐藏，切回在线模式时原来的地址、模型名和 Key 仍在。本机模式不需要 API Key，也不需要安装 Ollama。

使用 WebLLM 在浏览器的 WebGPU 上运行量化的 `Qwen3-0.6B-q4f16_1-MLC`。首次需要联网下载数百 MB 的模型，并缓存网页和运行库；显存需求约 1.4 GB，另需留出三维场景的开销。先以支持 WebGPU 的桌面浏览器为目标。下载由用户点击触发，模型运行库按需加载，不会在普通在线模式下加载。

本机模型先提供四种基础动作：观察、移动、转向、升降身体。可以试「向前走一米」「右转九十度」「把身体抬高到一米」。每条指令独立执行，不带入之前的对话，每次最多进行 6 轮模型调用。复杂任务、物品操作和模型主动写记忆请使用在线模式。小模型可能遗漏参数或理解错误；动作仍经过现有工具校验，失败结果会交回模型，每次动作也能用「停止」中断。

对话仍记录到本机日记；日记摘要复用同一个本机模型，不会回退到在线 API。摘要与动作共用一个串行推理队列，取消某条指令不会取消其他排队请求。较长的内容可能超过本机上下文限制，自动整理失败时沿用现有的裁剪策略。

正式构建加载成功后，可以断网重开页面，再点「加载本机模型」从缓存加载。网页由 Service Worker 缓存，权重、分词器和 WASM 由 WebLLM 缓存。浏览器清理站点数据或回收缓存后需要重新联网下载。「释放显存」卸载当前模型，保留下载缓存。云端进度同步仍需要网络。

网页离线缓存仅在 `pnpm build` 后的正式构建生效；`pnpm dev` 用于开发，不安装 Service Worker。部署支持根路径或子路径。新版本的离线缓存安装后，在旧页面全部关闭后接替旧版本；不缓存 API 响应和密钥，也不会清理 WebLLM 的模型缓存。
